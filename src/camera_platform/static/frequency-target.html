정확도 판정의 경계

목표는 영상면 센서 열 방향 native Nyquist의 일부입니다. Bayer RAW의 평균 광전자 변화가 안정돼도 RGB 시스템 MTF가 수렴했다고 판정하지 않습니다. 저장 기하 PSF의 보간은 새 광학 정보를 만들지 않으며, 같은 광선의 재추적은 회절·광선 밀도·실측을 검증하지 않습니다. 정책상 장면 크기 또는 작업 메모리를 초과하면 결과를 inconclusive로 남깁니다.

01 등록한 모델·ROI

기존 등록 active mode의 전역 센서 좌표를 사용합니다. 렌즈 revision UUID, 저장 센서 run SHA-256 및 선언 ID가 필요합니다. 선택한 영역만 계산하며 전체 FOV 촬영을 주장하지 않습니다.

등록·조회는 lens-sensor-active-modes API를 사용합니다. 이 화면은 등록 ID의 실제 제품 사양을 검증하지 않습니다.

전역 센서 ROI · 끝 좌표 제외

각 축 8–128 픽셀, 최대 16,384 픽셀. 단일-site monochrome의 선언한 주파수 점 평가는 각 축 최소 48 픽셀이 필요합니다.

Scene 격자와 정확도 목표

Adaptive 모드에서는 이 입력 shape를 실행 격자로 사용하지 않습니다. 센서 pitch, 목표 주파수, 고정 화각과 정책 상한에서 시작 격자를 계획합니다.

0과 1 사이에서 오름차순이며 목표 비율 이하여야 합니다. 1.0 자체의 edge endpoint는 현재 검사하지 않습니다.

이 입력은 격자 계획만 조정하며 alias 응답을 실제로 계산하지 않습니다. 정책 예산은 하드웨어 한계나 실행 시간 보장이 아닙니다.

PSF 해상도 경로

Adaptive에서 비워 두면 실행 격자 기준 선택. 명시적 모드에서 재추적을 택하면 입력 필수.

같은 광선 재추적은 저장 histogram bin 민감도 진단입니다. 광선 밀도·회절·ROI 위치별 물리 PSF 수렴을 뜻하지 않습니다.

실행 tile 설정

이 진단은 잡음 전 평균 광전자를 비교하며 ADC RAW·ISP를 실행하지 않습니다. Readout chunk는 등록 ROI 요청 계약을 유지하는 입력입니다.
