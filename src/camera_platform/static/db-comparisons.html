보유 렌즈와 센서 revision을 직접 고르세요.

저장된 렌즈 두 개의 기하학적 spot과 센서 두 개의 RAW를 같은 선언 조건에서 각각 비교합니다. 선택한 revision과 원본 입력은 작업 기록에 고정됩니다.

두 개의 별도 비교렌즈 2개 → geometric PSF · 중심/주변부센서 2개 → 8×8 이상 균일 장면 · RAW/광전자렌즈×센서 2×2 RAW 결합은 실행하지 않습니다.

01

비교 조건

DB 항목을 선택하면 코드를 수정하지 않고 실행합니다.

렌즈 DB · 서로 다른 revision 2개

실행 가능 표시는 저장된 geometric PSF가 이 파장에서 검증된 자산과 연결됨을 뜻합니다. 절대 광량과 픽셀 적분 응답을 뜻하지 않습니다.

센서 DB · 저장 실행 revision 2개

저장된 sensor run ID를 고정합니다. 실행 불가 항목은 이유를 보이되 선택할 수 없습니다.

공통 계산 조건

센서 장면은 균일 입력 uniform ee입니다. 같은 수치 입력은 같은 물리 화각이나 픽셀별 정합을 보장하지 않습니다.

공통 readout 값으로 덮어쓰기 · 선택 사항

비워 두면 각 DB revision의 저장값을 사용합니다. 서로 다른 readout 값 때문에 비교가 거부되면 서버가 필드명을 알려 줍니다. 그 필드에 공통 값을 명시하면 두 센서에 동일하게 적용됩니다.
