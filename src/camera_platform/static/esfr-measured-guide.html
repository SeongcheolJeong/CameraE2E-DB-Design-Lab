실물 E-SFR 차트로
112개 위치를 보정·검증하는 촬영 가이드

실측 Calibration 열기 · 기준점·ROI 편집기 ·

대상은 보유한 Imatest Extended E-SFR ISO 2023, 16:9 차트입니다. 카메라 모델과 RAW 형식이 확인되지 않았으므로 아래 수치를 장비 기본값으로 가정하지 않습니다. 실제 설정 기록과 native 파일을 준비한 뒤 업로드합니다.

한 작업의 순서

개발 촬영 3쌍 → 112개 ROI 검토 → 개발 RAW Gr로 후보 보정 → 후보·기준 고정 계약 → 별도 세션의 새 검증 촬영 3쌍 → 고정 후보 재시뮬레이션 → RAW 판정·ISP 진단 → DB 조건 연결·통합 보고서.

3+3은 이 시스템의 시작 프로토콜이며 ISO가 정한 표본 수가 아닙니다. 검증 데이터를 보고 보정했다면 그 자료는 개발 이력으로 남기고 다음 판정에는 새 검증을 취득합니다.

1. 장비와 촬영 모드를 확인합니다

첫 버전의 지원 범위

RAW는 명시적으로 디코딩된 Bayer byte 파일이며 unpacked8/unpacked16/MIPI RAW10·12·14를 지원합니다. 일반 분석기는 여러 CFA를 읽지만 이 112개 DB 보정 연결은 RGGB만 지원합니다. 현재 ISP는 같은 native raster의 PNG/JPEG/단일 페이지 TIFF이며, 확인된 linear 또는 sRGB encoding이어야 합니다.

DNG/CR2/CR3/NEF/ARW/YUV·제조사 container를 이름만 RAW로 바꾸어 제출하지 않습니다. binning, subsampling, resize, 회전, mirror, 미등록 crop 또는 unknown transfer는 이 경로에서 지원하지 않습니다. 필요한 native RAW·ISP 출력을 장비에서 확보해야 합니다. 원본 파일당 128 MiB, 촬영당 40 MP 한도가 있습니다.

3. 개발 3쌍과 112개 ROI를 등록합니다

  1. 동일 노출 설정으로 독립적으로 촬영한 3프레임의 RAW·ISP 쌍을 취득합니다. 역할은 development, session ID는 개발 세션, acquisition/frame ID는 각 노출마다 다르게 기록합니다.
  2. 실측 화면에서 빈 metadata JSON을 저장하고 실제 값으로 채웁니다. null을 임의의 “그럴듯한 값”으로 채우지 않습니다. 업로드 전 설정과 원본을 대조합니다.
  3. 기존 ROI 편집기에서 촬영을 선택하고 차트 기준 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래의 원형 기준점을 지정합니다. 제안은 좌표 찾기일 뿐 정확성 승인이 아닙니다.
  4. ROI JSON과 차트 프로파일을 실측 화면에 가져옵니다. 정확한 112개 edge ID, 서로 다른 native ROI, edge마다 가로·세로 최소 32px가 필요합니다. 왜곡·가림·경계가 있으면 직접 수정합니다.
  5. 각 촬영 원본 미리보기에서 112개 ROI 위치·clipping·glare·가림과 고정 배치를 확인합니다. 세 촬영 모두 검토한 다음 개발 보정을 실행합니다. ROI를 바꾸면 확인을 다시 합니다.

4. 후보 고정 후 새 검증 3쌍을 취득합니다

  1. 후보 hash와 취득 계약이 발급될 때까지 기다립니다. 검증용 템플릿에는 고정된 실제 조건과 계약 ID/hash가 복사됩니다.
  2. 새 session ID로 후보 고정 시각 이후 동일 노출 설정의 독립 3프레임을 취득합니다. 카메라·차트·focus·exposure·gain·ISP 설정을 유지합니다. 고정 지그를 해체하거나 다시 framing한 촬영은 현재 공통 ROI 계약에 적합하지 않습니다.
  3. captured_at과 원본 frame ID, 취득 검토자와 확인 항목을 기록합니다. 파일 이름이나 재인코딩만 바꾼 개발 원본은 새 검증이 아닙니다.
  4. validation 역할로 업로드하고 각 촬영의 같은 112개 ROI를 확인한 뒤 검증을 제출합니다. 검증에서 후보를 다시 피팅하지 않습니다.
  5. 전체 위치의 RAW·ISP 영상/SFR·오차와 기준 초과 항목을 확인합니다. 실패도 보고서에 보존합니다. 작업 URL의 workflow ID로 다시 열거나 중단된 계산을 재개할 수 있습니다.

촬영 시각·장비·검토 확인은 operator 선언입니다. 서버는 계약·원본 hash·자료 분리·시간 순서의 일관성을 확인하지만 외부 카메라의 정체나 실제 노출 시각을 독립적으로 인증하지 않습니다.

5. RAW와 ISP의 판정 범위를 구분합니다

보정 목적함수는 개발 RAW Gr SFR입니다. 차트·렌즈·센서·픽셀 효과가 섞인 조건부 Gaussian 유효 응답을 맞춥니다. MTF 크기만으로 비대칭·위상까지 포함한 순수 렌즈 PSF를 유일하게 복원하지 않습니다. QE·Dark·PTC를 이 edge 촬영으로 새로 추정하지 않습니다. 아래 IQ 옵션은 별도의 색 패치에서 조건부 reference ISP 보정을 수행합니다.

현재 작업의 ‘보정 전 기준’은 초기 Gaussian 응답(기본 σ=1.5 native pixel)입니다. 선택한 DB 렌즈 처방에서 직접 계산한 PSF로 표시하지 않습니다. DB 실행·후보·조건 ID에 보정 프로파일과 보고서를 연결하며, 실제 장비와 DB 광학계의 대응은 별도로 확인해야 합니다.

제조사 ISP가 불명확하면 comparison_mode: diagnostic으로 ISP 잔차를 기록하고 RAW 기준만 판정합니다. linear/sRGB 역변환은 영상 encoding 처리이며 demosaic·CCM·NR·sharpening·tone mapping 일치의 증거가 아닙니다. matched_bilinear는 실제 출력이 선언된 고정 bilinear 파이프라인과 일치할 때만 사용합니다. Imatest gamma·tonal response 설명.

자동 보고서에는 개발/검증 ID·역할, 후보 고정 계약, native 좌표, 원본/결과 hash, 112개 범위와 누락·실패, 전체/최대 오차, ISP 진단 여부, DB 프로파일 적용 여부를 남깁니다. 활성화되지 않은 후보도 보존하며 이전 활성 모델을 실패한 후보로 덮어쓰지 않습니다.

6. 색·계조 IQ 옵션: 기준과 데이터 범위를 먼저 고정합니다

IQ를 켜면 112개 edge 외에 18개 색 패치·20개 계조 패치 ROI를 각 촬영에서 확인합니다. 실제 인쇄물의 실측 반사율 대신 imatest_esfr_2023_nominal_v1 명목 설계값을 사용하므로 절대 색 정확도 인증이 아닙니다. 기준 ID/hash와 모든 패치의 clipping·제외 원인을 보고서에 남깁니다.

실제 ISP 색 공간은 확인된 sRGB 또는 미확인으로 선언합니다. sRGB encoding과 sRGB 색 공간은 별개입니다. 미확인 출력의 ΔE는 미제공으로 남기며 값을 0으로 채우지 않습니다. 명목 타깃·보정 전 reference ISP·WB/노출 스케일/CCM 후 reference ISP·실제 ISP를 비교합니다. 같은 RAW를 사용하며 실제 제조사 ISP 출력은 변경하지 않습니다.

개발 3프레임에서 WB·노출 스케일·CCM과 명목 반사율→관측 응답의 계조 전방 모델을 맞춥니다. 계조 전방 모델은 영상에 추가 적용하는 tone correction이 아닙니다. 후보 고정 뒤 새 검증에는 피팅하지 않습니다. IQ 허용치는 아직 정하지 않았으므로 판정 대기이며 복합 후보를 자동 활성화하지 않습니다.

노이즈는 기본 3프레임으로 계산합니다. 같은 역할·조건의 추가 0–5프레임을 등록하면 총 3–8프레임이며, 반복 안정성을 위해 8프레임을 권장합니다. 이 숫자는 시스템 프로토콜이며 ISO 요구가 아닙니다. 추가 촬영도 38개 패치를 검토하고 기본 3개와 ID가 겹치지 않게 합니다. 개발에서 선택한 추가 수를 고정하고 검증도 같은 수를 새로 취득합니다. 노이즈 반복은 CCM 피팅에 추가하지 않습니다.

RAW R/Gr/Gb/B 및 실제 ISP RGB의 공간·시간 변동을 구분합니다. 시간 변동에는 조명 드리프트도 포함되므로 Dark/PTC, sensor gain, full well 또는 카메라 전체 DR을 뜻하지 않습니다. 계조 차트가 보여 주는 반사율 범위 안에서만 해석합니다.

일반/HDR 등 모드를 비교하려면 각 모드의 고정 조건으로 보정·새 검증을 완료한 두 workflow ID를 입력합니다. 같은 차트·ROI·광학/조명 조건에서 mode/exposure/gain 차이만 비교하며, 한 작업 안에서 조건을 느슨하게 섞지 않습니다. HDR 합성·동적 물체·flare·전체 DR 검증은 포함되지 않습니다.

표준·측정 범위

ISO 12233:2023은 후속 2024판으로 대체되었습니다. 이 경로는 보유한 2023 차트 형상과 engineering SFR 분석을 지원하며, ISO 조항별 적합성이나 인증을 선언하지 않습니다. 실측 촬영을 업로드했다는 사실과 독립 물리 검증 확립은 별개입니다. ISO 12233:2023 · ISO 12233:2024.

이 문서는 장비 미지정 상태의 일반 입력 가이드입니다. RAW 형식과 실제 ISP 출력이 확인되면 해당 장비의 검증된 설정으로 템플릿을 작성합니다.
