이 작업실의 적용 범위

기하 광학 PSF와 저장 센서 응답의 결합 진단입니다. 렌즈 radiometry·CRA·회절은 검증되지 않았고, 가상 RAW 창은 실제 센서 위치가 지정된 crop이 아닙니다. HDR은 정적 두 노출, LFM은 가정하거나 출처와 함께 선언한 PWM·행 시간만 다룹니다. ISP는 같은 원본 RAW를 재처리하며, cohort는 원본 RAW를 보존합니다. 실측 성능·제품 순위·인식 정확도는 여기서 판정하지 않습니다. 기존 저장 센서 단독 HDR/LFM/화질 작업은 저장 센서 작업실에서 따로 실행합니다.

01 Lens DB × Sensor DB 정수 RAW

기존 geometric raytrace PSF와 저장 센서 snapshot으로 정수 RAW를 계산합니다. 중앙 계산 또는 저장된 시야별 PSF를 국소 패치에 적용할 수 있습니다. 절대 투과·상대조도는 unity 가정이며 주변부 위치·CRA는 재현하지 않습니다.

서로 다른 렌즈·센서에 같은 입력 장면 각도 범위를 적용합니다. 출력 RAW의 각도별 픽셀 간격과 2×2 품질 비교 가능성은 별도로 검사합니다.

02 Lens × Sensor 정적 RAW HDR

선택한 렌즈와 저장 센서의 같은 정적 D65 장면을 두 노출로 촬영합니다. 결합 HDR 계산은 FPN을 0으로 고정하며, 유효 융합 픽셀이 없으면 결과가 inconclusive일 수 있습니다.

03 Lens × Sensor PWM/LFM 진단

선택한 렌즈와 센서 응답으로 이상적인 PWM을 행별 적분합니다. 기본 경로는 가정한 20 μs 행 시간을 쓰며, 출처 결속 모드를 선택하면 등록한 시간 선언의 값을 씁니다. 실제 제품 LFM/HDR 모드 성능 보증은 아닙니다.

선택 센서·RAW 크기·노출쌍으로 시간 모드 template/import API를 먼저 실행한 뒤 받은 SHA를 입력하세요. 출처 문서의 수치 자체는 자동 검증되지 않습니다.

03A 저장 PWM RAW의 HDR 복원

완료된 Lens × Sensor PWM/LFM 원본 2노출 × 4위상 RAW를 다시 촬영하지 않고 복원합니다. 두 노출 융합, 단일 노출 fallback, 무효 픽셀을 구분합니다. 행 시간과 PWM은 선언한 모델 조건이며 제품 mode 사양이 아닙니다.

04 보존 RAW 고급 ISP 재처리

완료된 Lens × Sensor RAW 작업의 동일한 정수 RAW에 고정 WB·CCM·tone·bounded sharpen을 적용합니다. 입력 RAW를 다시 촬영하지 않습니다. RGGB만 지원하며 Quad Bayer·mono 출처는 서버가 거부합니다. 저장 센서 단독 출처는 기존 작업실을 사용하세요.

고정 ISP 프로필

예: 1,0,0, 0,1,0, 0,0,1 · 각 계수 −8…8, 각 행의 절댓값 합 ≤16

Sharpen threshold와 max delta는 서버 template의 고정값을 사용합니다. LSC·denoise는 capture-domain calibration이 없어 bypass로 고정되며 이 작업에서 활성화할 수 없습니다.

05 보존 RAW 데이터셋

완료된 저장 센서 화질 작업 또는 Lens × Sensor RAW의 원본 정수 RAW 한 장을 재촬영 없이 복사합니다. Lens RAW에는 사용자 제공 RAW 좌표 라벨을 선택적으로 결속할 수 있습니다. 여러 Lens RAW를 묶으려면 다음 cohort 단계를 사용하세요.

박스는 원본 RAW mosaic의 좌상단을 원점으로 하는 반개구간 [x1,y1,x2,y2]입니다. RGB 출력 좌표가 아니며, 제공 라벨의 진실성은 자동 검증하지 않습니다.

작업 간 RAW 중복 제거 또는 train/test 독립성은 검사하지 않습니다. 서로 다른 export에 같은 RAW가 들어갈 수 있습니다.

06 Lens × Sensor RAW cohort

완료된 결합 RAW 작업 2–64개를 split과 함께 선택합니다. 동일 RAW가 서로 다른 split에 있으면 서버가 거부합니다. 이 cohort 밖의 export와 중복되는지는 검사하지 않습니다.

선택 0개

07 저장 Lens × Sensor 2×2 비교

완료된 결합 RAW 4개에서 렌즈 2개와 센서 2개를 한 번씩 선택합니다. 같은 물체 각도 ROI와 충분한 장면 표본이 확인되면, 기존 CameraE2E PSF 계산을 거친 RAW의 edge 응답을 cycles/degree로 비교합니다. 그 외에는 개별 edge 진단만 보입니다. 독립 반복 프레임이 없으면 temporal SNR은 표시하지 않습니다.

08 기존 Adaptive Laplacian ISP

완료된 Lens × Sensor 원본 RAW에 기존 CameraE2E의 Adaptive Laplacian demosaic를 적용하고 같은 RAW의 bilinear 출력과 비교합니다. 최소 10×10 RAW가 필요하며, 차이 자체는 화질 개선 점수가 아닙니다.

09 로컬 검출기 개발 실험 · 저장 ISP RGB

저장된 Lens RAW와 그 ISP sRGB에 로컬 YOLO11n을 실행합니다. 운영자가 가중치 SHA를 명시적으로 신뢰하지 않으면 제출할 수 없습니다. 이 선언은 가중치 원배포 진위 확인이나 OS 수준 네트워크·파일 격리가 아닙니다. 8–32픽셀 시뮬레이션은 검출 정확도를 평가하기에 너무 작습니다. 빈 검출도 실제 추론 출력으로 보존하고, mAP·제품 인지 성능은 판정하지 않습니다.

독립 제공 annotation과 예측의 단일 프레임 평가에는 인지 import·평가 API를 사용합니다.
