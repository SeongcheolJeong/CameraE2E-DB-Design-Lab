# PWM 정수 주기 노출 AE — 개발 소스 0.16.1.dev10

이 확장은 `camera_electrical_exposure_policy_v2`를 선택한 촬영 프로그램에만 적용된다. 기존 v1 정책과 저장 결과의 해석은 유지한다. 목적은 PWM 광원에서 기본 AE가 8 → 4 → 8 → 4 ms로 번갈아 적용하던 작성 사례를, 선언된 PWM 주기에 맞는 노출 후보로 제한하고 목표 미달을 숨기지 않는 것이다.

## 입력과 계산 계약

- 정책의 `period_lattice`는 `{"kind":"whole_pwm_period_v1","period_ns": ...}`이고, 실제 PWM 파형의 주기와 정확히 같아야 한다. 파형은 켜짐 시간이 0보다 크고 주기보다 작은 비상수 PWM이어야 한다.
- 가능한 노출은 `exposure_grid_ns`의 시작점·간격과 PWM 주기의 정수배에 동시에 속해야 한다. 이 교집합이 비어 있으면 입력을 거절한다. 초기 적용 노출도 교집합에 있어야 한다. 교집합은 정수 최대공약수와 합동식으로 계산해 큰 격자를 나열하지 않는다.
- 제어기는 원본 정수 RAW 코드의 선택 CFA 사이트 합계와 ADC black code만 관측한다. 광전하, 조도, trap 내부 상태, 미래 프레임이나 ISP 출력에서 밝기를 역산하지 않는다. 명령은 원래의 선언된 지연과 프레임 latch 이후에만 적용된다.
- PWM 주기의 정수배라는 기하학적 조건은 이상적인 반복 파형의 윈도우 적분 조건일 뿐이다. rolling row, 움직임, trap 잔류·방출, 실제 드라이버 지터까지 같은 RAW 값을 보장하지 않는다.

화면의 프로그램 편집기에서 정책 주기를 바꾸면 작성 파형의 주기도 함께 바뀐다. 별도로 버전 고정된 프레임 시퀀스의 초기 노출은 자동 변경하지 않는다. 변경한 주기와 초기 노출이 맞지 않으면 실행 전 검사가 거절하므로, 호환되는 시퀀스를 별도로 선택하거나 작성해야 한다.

허용 노출이 현재값 하나뿐이고 관측이 목표 밖이면 정책 상태는 `period_lattice_hold_outside_target`이며 명령을 만들지 않는다. 결과에는 허용 노출 수, 실제 적용값, 각 프레임 관측, 목표에 들어온 프레임 수가 남는다. 유한 RAW 시퀀스만으로 **모든 허용 노출에서 목표가 불가능하다**고 단정하지 않는다. 따라서 `target_feasibility`는 `not_established_by_finite_raw_sequence`, 물리 LFM 성능은 `not_established`다.

## 재현 사례와 확인 결과

작성한 8×8 정적 장면, 8 ms 주기·4 ms 켜짐 PWM, trap 상태 4프레임에서 v1 기본 정책은 8/4/8/4 ms, 관측은 571.6875/21.65625/576.90625/22.28125 DN으로 목표 200–300 DN에 0/4였다. v2는 허용 노출이 8 ms 하나여서 8/8/8/8 ms를 실제 적용했고, 관측은 571.6875/606.75/584.21875/608.875 DN으로 역시 목표에 0/4였다. **진동 방지와 목표 달성은 별개**다.

관련 Python 194개, 브라우저 단위 테스트 306개, 기존 v1 저장 NPY 51개 exact 재구성 검사를 통과했다. 분리된 QA 상태에서 실제 Worker 작업 2건, 최초 HTTP 146개·같은 상태 재시작 HTTP 148개, 최초·재시작 브라우저 결과를 확인했다. 새 소스는 설치하거나 기본 앱으로 승격하지 않았다. 상세 원본과 검사 결과는 [dev10 근거](../reports/camera_platform/pwm-period-v0161/evidence-summary.json)에 고정한다.

## 다음 설계 경계

이 정책은 하나의 주기 격자와 노출만 제어한다. 목표 밝기와 PWM 정수 주기 사이의 상충은 gain/HDR 경로, 포화, 잡음, 움직임, trap 상태를 포함한 별도 설계 문제가 된다. 다음에는 상태 이력을 보존하는 다중 노출·gain HDR, CDS/reset 동역학, 움직임 대응 ISP, 제약을 명시한 다목적 최적화를 서로 다른 모델 계약으로 확장해야 한다. 독립 실측은 0건이며 카메라 물리 정확도, LFM 성능과 총 예측 불확실도는 확립되지 않았다.
