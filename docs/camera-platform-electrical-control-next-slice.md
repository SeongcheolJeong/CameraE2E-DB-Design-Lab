# 다음 범위: 전달 RAW를 관측하는 전기 모델 AE

2026-09-23에 작성한 **과거 설계 제안**이다. 단일 readout의 RAW 관측 노출 AE는
2026-09-24 소스 `0.16.1.dev3`에 구현했다. 현재 동작과 실제 검증 범위는
[전기 AE 구현 계약](camera-platform-electrical-control.md)을 따른다.
아래 제안의 모든 항목, 특히 settling 정의·LFM 비교가 완료됐다는 뜻은 아니다.
원래의 7개 모듈·4개 실행 모드와 일반 광학·픽셀·전기 모델 목표는 유지한다.

현재 `closed_loop.py`는 완료된 프레임의 RAW 통계로 AE/AWB 명령을 생성하고,
명령 도착 시각·구동 지연·프레임 지연을 지난 latch에만 적용한다. 그러나 native
4사이트 응답을 거부하며 일반 전기 readout과 retained PD 상태를 운용하지 않는다.
`retained_charge_runtime.py`는 반대로 native PD의 상태와 전기 readout을 계산하지만
미리 기록된 제어 시퀀스를 입력받는다. 이 두 구현의 상태와 시간 계약을 연결해야 한다.
기존 거부 조건을 제거하는 것만으로 전기 폐루프가 되지는 않는다.

첫 설계 질문은 “밝음→어둠 또는 PWM 입력에서, 전달 코드만 보는 노출 제어가
어떤 지연과 잔류 응답을 만들며 목표 코드 범위로 돌아오는가?”이다. 첫 범위는
고정된 단일 readout 경로의 **노출 AE**다. Gain·색 처리·PD clear 정책은 고정한다.
DCG 경로 전환, AWB, HDR 합성, 광원 위상 추정과 LFM 최적화는 별도 확장이다.

## 필요한 모듈 경계

- 촬영 세션은 동일 native 센서의 PD 상태, PRNU와 난수 상태를 소유한다.
  프레임 호출 사이의 저장 전하를 유지하고 재시도는 고정 초기 상태에서 시작한다.
- 컨트롤러는 선택한 경로의 integer RAW, 실제 적용 노출, gain, 원본 clock,
  관측이 사용 가능해진 시각만 받는다. 장면의 미래, noiseless 전하, overflow truth,
  PD reservoir, 원래 PWM 위상은 관측 입력으로 넘기지 않는다.
- 관측은 signed black-relative DN의 명시적 ROI 통계다. R/Gr/Gb/B의 제외·집계
  규칙을 고정한다. 이 코드 통계는 현재 장면의 광전하나 물리 휘도가 아니다.
- 별도의 순수 정책이 고정 노출 grid와 목표 코드 범위에서 명령을 제안한다.
  광전하 역산, 임의 gain 또는 자동 RAW 형식 변경은 허용하지 않는다.
- 명령 큐는 `source_frame_id → statistics_ready → controller_complete → arrival
  → actuator_ready → applied_frame_id`를 기록한다. 동일 시각 경계와 최소 프레임
  지연을 명시하고, 적용되지 않은 명령도 대체·만료·미도착 이유를 보존한다.
- 전기 캡처 프로그램, 정책, 센서·광학 모델, ROI, 난수 seed와 초기 상태를 Test와
  하나의 Worker 작업에 고정한다. 계획 단계에서 가능한 최대 노출의 장면 범위와
  행별 겹침, 정수 시각 overflow, 메모리·번들 크기를 검사한다.

## 결과와 판정

각 프레임에 명령된 값과 실제 적용값을 구분한다. 제어 오차는 작성자가 선언한
코드 목표에 대한 값이며, “적정 노출”이나 photometric accuracy로 표현하지 않는다.
최종 ADC rail 비율은 표시하되 이를 PD full-well clipping truth로 바꾸지 않는다.
고정 제어와 폐루프 제어는 같은 입력·원래 시계·난수 정책으로 각각 계산하고,
실제로 변한 RAW/RGB와 적용 이벤트를 보존한다.

settling은 관측 가능한 프레임 수와 선언한 허용 구간으로 정의한다. 유지 시간,
overshoot와 미도달을 함께 기록하고, PWM 때문에 관측이 교대로 바뀌는 경우를
정상광 수렴과 합치지 않는다. 작아진 시간 변화량을 LFM 개선으로 해석하지 않는다.
시간 ISP를 뒤에 연결할 때는 제어용 관측이 RAW인지 처리 출력인지 명시한다.
숨은 필터 상태가 AE 지연을 바꾸는 일을 피해야 한다.

## 필요한 반례와 종료 조건

1. 명령의 숫자만 변하는 구현을 검출한다. 적용된 노출 변화가 실제 적분 RAW를
   바꾸고 latch 이전 프레임에는 영향을 주지 않아야 한다.
2. 완성 전 RAW나 미래 프레임이 정책에 들어가지 않아야 한다. 큰 정수 clock과
   경계 시각에서도 command-ready 조건을 지킨다.
3. PD clear가 없는 bright→dark에서 이전 전하가 계속 관측에 기여하는 경우를
   포함한다. 현재 노출 나누기로 이를 제거한 것처럼 보이는 결과를 거부한다.
4. PWM과 노출 window를 함께 적분한다. 같은 effective exposure만으로 서로
   다른 위상·움직임의 결과를 같다고 판단하지 않는다.
5. 최대/최소 노출, grid, timeout, 취소, 재실행, 전원 없는 초기 상태, 원본 손상과
   지연 때문에 마지막까지 적용되지 않는 명령을 확인한다.
6. 실제 Workbench에서 정책 작성→고정 Test→실행→명령/적용/RAW 비교→원본
   번들까지 연결하고 재시작 후 동일 기록을 확인한다.

독립 실측 없이 제어기 안정성·실제 센서 지연·상용 LFM 성능을 인증하지 않는다.
이 제안의 완료도 전체 상용제품 목표의 완료를 뜻하지 않는다.
