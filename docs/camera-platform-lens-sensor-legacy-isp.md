# CameraE2E spectral ISP on a retained Lens × Sensor RAW

The `lens_sensor_legacy_isp` job reprocesses one completed Lens × Sensor RAW capture with the existing `pyisetcam.ip_compute()` path. It reconstructs the selected saved `db_estimate_v1` sensor's RGB EQE and readout, supplies the **exact stored int32 mosaic** to the ISP, and uses CameraE2E's D65 Macbeth sensor-to-XYZ and display transforms. The job does not run a new exposure or change the original RAW.

The accepted source is a completed native 2×2 three-channel RGGB Lens × Sensor RAW job whose saved scene is explicitly `uniform_d65` or `slanted_edge_d65` at the 450/550/650 nm scene sampling used in the source capture. The available demosaic methods are `bilinear`, `laplacian`, and `adaptive_laplacian`. An unsupported method, CFA, readout drift, missing offline asset, different sensor snapshot or unspecified illuminant is refused before processing. The `acknowledge_model_derived_color_limits` field is required.

The registered object-radiance scene workflow produces Lens × Sensor RAW but is not yet an accepted source for this D65-only color transform. Its arbitrary illuminant has no approved white-point or measured color-calibration contract. Nested Display creation uses the pinned local ISETCam asset store throughout the ISP calculation, including in an installed Worker without network access.

Use `GET /api/v1/lens-sensor-legacy-isp/template?source_lens_sensor_job_id=<id>` to obtain the exact request and selected source contract, then set the acknowledgement and submit it to `POST /api/v1/lens-sensor-legacy-isp`. Poll `GET /api/v1/lens-sensor-legacy-isp/<job_id>` and export the report with `GET /api/v1/lens-sensor-legacy-isp/<job_id>/export`.

The saved NPZ contains `source_raw_dn_frame`, once-black-subtracted `normalized_sensor_dn`, `sensor_rgb`, `model_derived_xyz`, `display_rgb`, and `srgb`. The report pins the source binding, Sensor DB revision and model snapshot hash, CameraE2E ISP implementation hashes, upstream asset hashes, native CFA, readout, D65 scene, and computed fixed color matrices. Readback checks the stored RAW against the source bytes and verifies linked report/array hashes.

The color matrix is a **model-derived D65 fit from the saved estimated EQE**. It is not a measured CCM or measured color accuracy. The current Lens DB PSF is geometric and excludes diffraction; its transmission and relative illumination are unknown unity assumptions. CRA and pixel angular response are not coupled, and the sensor readout may use generic assumptions. Pixel-level output differences between methods are software diagnostics; they do not establish optical MTF, perceptual quality improvement, or product ranking. This job is a constrained reuse of CameraE2E ISP, not a general ISP graph, HDR merge, temporal denoiser, or hardware timing model.
