# Angular-response calibration candidates

`camera_platform.calibration.propose_angular_calibration(base_sensor_model, observations, parameter_bounds)`
creates an **unapproved model candidate** for the current static angular-shading runtime. It returns
`PROPOSED` or a structured `REFUSED` report. It does not modify its inputs, register a model, approve a
release, or perform independent validation. The application service owns immutable registration and
resolves every measurement, model and capture from the registry before invoking this pure function.

## What can change

The fitted parameters are one dimensionless scale per existing **nonzero sensor angle node** for
each of R and B. A scale applies uniformly to every wavelength at that channel/angle. Green response,
zero-angle response, normal-incidence QE, angular/spectral coordinates, lens response, irradiance,
pixel area, readout and acquisition conditions are fixed. The normal-incidence relative response
remains exactly one. A different spectral-response shape, lens model, noise model or temperature
dependence needs a different calibration model; this fitter cannot infer those causes.

For sensor angle nodes `[0, 15, 30]` degrees, bounds have two entries per channel:

```json
{
  "R": {"min": [0.5, 0.5], "max": [1.5, 1.5], "unit": "1"},
  "B": {"min": [0.5, 0.5], "max": [1.5, 1.5], "unit": "1"}
}
```

Every lower bound must be nonnegative and strictly below its upper bound. Each upper bound is also
limited by `QE(normal, wavelength) × relative_response(wavelength, angle) × scale ≤ 1`. A request with
no feasible interval is refused. The report preserves both requested and effective bounds and shows
which fitted parameters reach a bound. A parameter at its bound is a diagnostic, not approval.

## Observation contract

Each observation supplies these immutable inputs:

```text
measurement       registered raw.channel_ratio record and original provenance
lens              the corresponding fixed lens response payload
stimulus          wavelength_nm, spectral_irradiance_w_m2_nm, reference_plane
conditions        exactly the measurement's unit-bearing capture conditions
sampling          the exact continuous-point or RAW ROI observation operator
saturation_diagnostics  registered capture analysis evidence for physical data
```

The metric must be dimensionless `raw.channel_ratio` at `sensor_raw`, ordered as R/G then B/G. Its
included effects must match the implemented static response chain. Stimulus coordinates must exactly
equal the sensor wavelength axis; the irradiance plane is `sensor_surface`, with on-axis lens
throughput already included. Gain must match the readout model, and all conditions must lie inside
the base model's declared domain. This static model fits one temperature at a time. No implicit unit
conversion, wavelength resampling, coordinate sorting or missing-value substitution occurs.

Two observation operators are supported:

- `continuous_dark_corrected_expectation`: one ratio pair at each lens field knot. This is restricted
  to synthetic implementation fixtures. It cannot substitute for sampling a physical RAW image.
- `raw_roi_channel_mean_ratio`: average the same piecewise-linear radial basis at the actual R, G
  and B positions in each ROI. The operator is generated by
  `camera_platform.measurement.observation_sampling_weights`. Nominal ROI field labels identify
  samples; they are not used as a substitute for the actual pixel geometry.

For RAW observations, the measurement contains `observation_method.id = raw_roi_observation_v1`, its
frozen specification and hash, and `sample_geometry`. The fitter recomputes weights from that
specification and requires exact agreement. It checks bit depth and black level against the fixed
sensor model. Physical observations require `native_sensor` full-sensor/crop geometry; representative
normalized rasters remain synthetic. The CFA phase and crop origin are retained. Both the ordinary
ASCII canonical hash and Unicode ROI identities follow the shared RAW observation implementation.

`mean_dark_frame` uses the photo-signal expectation after matched dark subtraction.
`black_level_only` retains the modeled mean dark charge in both numerators and the green denominator.
ADC rounding, sample noise, dark-frame sampling error and optical model error remain unquantified
prediction uncertainty.

## Linear system and identifiability

Let `C[c,f,k]` be the known electron contribution for channel `c`, field knot `f`, and sensor angle
node `k`. It includes spectral photon integration, original QE/relative response, interpolated lens
angular power weights, relative illumination, exposure and pixel area. Let `W[r,c,f]` be the frozen
ROI/CFA averaging weights. For R or B:

```text
fixed[r,c] = sum_f W[r,c,f] * C[c,f,0] + retained_mean_dark
A[r,k]     = sum_f W[r,c,f] * C[c,f,k]              for k > 0
G[r]       = sum_f W[r,G,f] * sum_k C[G,f,k] + retained_mean_dark
ratio[r,c] * G[r] = fixed[r,c] + sum_k A[r,k] * scale[c,k]
```

`G` must be finite and positive. Rows are divided by `G` before fitting, giving equal weight per
observed ratio. No measurement covariance or statistical independence is invented. Each channel is
fitted with SciPy `lsq_linear` under explicit bounds. The coefficient matrix must have full column
rank and condition number at most `1e8`; otherwise the report asks for additional independent
incident-angle distributions. Duplicate training dataset IDs are refused. The entire allowed
parameter box is checked against the declared full-well/ADC capacity before using this linear fit.

The report includes rank, singular values, condition number, scales, active bounds, and before/after
training ratio residuals. A low training residual does not prove the optical explanation is correct.
The method has no parameter for arbitrary ISP corrections, wavelength-specific changes, temperature
dependence, or nonlinearity; unexplained residuals remain visible.

## Physical evidence and release boundaries

Synthetic observations use `simulated`, `estimated` or `synthetic` source metadata. Their report has
`physical_evidence: false` and `evidence_kind: implementation_verification`. Physical and synthetic
observations cannot be pooled into the same fit.

A physical calibration fit requires a single identified camera instance, instrument identity and
calibration revision. It also requires the stored
`measurement.instrument.saturation_diagnostics` to match the supplied capture analysis:

```json
{
  "source": "raw_roi_observation_v1",
  "linear_unsaturated": true,
  "saturated_samples": 0,
  "total_samples": 2048
}
```

Additional recorded diagnostic fields are retained and included in the equality check. ADC-code
checks alone cannot detect hidden full-well clipping. Therefore
`instrument.linear_response_evidence` must contain `confirmed: true`, `method_and_version`, and
`source_uri` for the external linearity evidence. The registry is responsible for resolving these
claims from stored capture records; the pure function cannot authenticate equipment or lab claims.

Even with physical training data, `physical_validation_pass` and `independent_validation` remain
false, `approval_status` remains `unapproved`, and candidate `uncertainty` remains `{ "kind": "unknown" }`.
The candidate preserves the union of inherited and new `calibration_dataset_ids`, and its input
manifest freezes measurement/lens/stimulus/sampling hashes and bounds. Register it as a new sensor
model revision with the base model as its parent. A subsequent validation must use different
datasets: reusing a training dataset is rejected by the platform's validation contract.

## Verified synthetic scope

The tests recover planted R/B angular scales, then apply the candidate to an unused lens angular
distribution and a different spectrum. That holdout demonstrates mathematical generalization
within the synthetic model family, **not physical camera validation**. A separate test generates
quantized RAW through CameraE2E, measures CFA-specific ROIs with the shared observation operator,
and recovers the planted scales within ADC-rounding tolerance. Refusal tests cover wrong units,
coordinates, geometry and effects, nonfinite inputs, deficient/ill-conditioned designs, saturation,
invalid bounds and missing physical evidence.
