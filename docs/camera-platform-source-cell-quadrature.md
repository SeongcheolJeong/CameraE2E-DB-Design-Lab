# 선택형 장면 소스 셀 면적 샘플링

개발 소스의 3D 장면 렌더 요청은 기본적으로 각 native 픽셀 중심에서 같은 방향의 광선을 `samples_per_pixel`번 추적한다. 따라서 경계가 픽셀 안을 가로질러도 경계의 면적 비율은 나타나지 않는다. `source_pixel_quadrature`는 이 입력 단계에만 2×2, 4×4, 8×8 또는 16×16 midpoint 격자를 선택적으로 적용한다.

```json
{
  "source_pixel_quadrature": {
    "model": "native_sensor_area_midpoint_grid_v1",
    "grid_side": 2
  }
}
```

각 소스 셀의 서브셀 광휘를 같은 가중치로 평균한 뒤 그 **native 소스 셀 중심**에 하나의 분광 광휘값으로 놓는다. 실제 광선 계산 수는 halo를 포함한 소스 행×열×파장 수×`grid_side²`×`samples_per_pixel`이며 262,144를 넘는 요청은 실행 전에 거부한다. 요청의 seed, 격자 중심·가중치·샘플 순서와 실제 경로 수가 결과에 남는다. 이 옵션이 없는 기존 요청과 결과의 기본 형식은 유지한다.

깊이·첫 물체 ID·적중 여부는 계속 픽셀 **중심 광선**의 보조 정보다. 면적 평균 광휘와 이 보조 정보를 같은 공간 의미로 해석하면 안 된다. 후속 렌즈 PSF는 수신 픽셀에 적분된 별도 응답이고, 여기서 수신 개구를 또 적용하지 않는다. 그러나 소스 위치를 서브셀별로 이동시켜 각 위치의 PSF를 적분한 연속 장면→렌즈 전달은 아직 아니다. 3D 재질·가림·광학 수차의 물리 정확도나 전체 오차 상한도 입증되지 않았다.

독립 면적 기준 반평면 시험에서 50.01% 밝은 셀은 기본 중심 광선의 전체 밝기와 달리 2×2에서 50%가 된다. 경계가 30%인 셀의 계산값은 2×2에서 50%, 4×4와 8×8에서 25%, 16×16에서 31.25%다. 따라서 이 사례의 16×16 잔여 면적 오차는 +1.25%p이고, 격자를 늘려도 매 단계 단조롭게 개선되지는 않는다. 자원 예산은 실제 halo 포함 소스 행×열×파장 수×`grid_side²`×경로 샘플 수에 적용된다.

별도 오라클은 30% 경계의 정확한 소스 셀 면적을 직접 계산하고, 비대칭 3×3 단위합 PSF의 수신값을 FFT 없이 직접 합산한다. Renderer→투영→이산 PSF 경로는 해당 격자 입력에 대한 직접 합산값과 일치했고, 전체 이산 합성 광량은 보존되며 센서 crop 밖 손실은 별도로 기록됐다. **이 보존은 샘플링된 이산 입력에 대한 성질이다.** 16×16의 +1.25%p 입력 편향까지 보정하거나 연속 장면의 서브셀 위치별 PSF를 입증하지 않는다. 1×1 단위합 PSF도 소스 셀 평균을 이웃으로 다시 퍼뜨리지 않는다. 이는 가림 경계 입력의 근사 개선과 한계를 보여 주는 합성 계산 검사이며, 실측 렌즈·센서와의 물리 검증은 아니다.

저장한 분광 광휘의 재투영은 원래 렌더 요청·아티팩트와 서브셀 격자, seed, 경로 수, 좌표·가중치 요약이 일치할 때 같은 **소스 셀 평균값**에 새 절대 투영 계수를 적용한다. 재투영은 Mitsuba를 다시 호출하거나 잃어버린 서브셀별 광휘를 복원하지 않는다. 결과에 `continuous_scene_psf_integration: false`를 유지하며, 이를 서브셀 위치별 렌즈·수신 개구 적분으로 해석하지 않는다.

별도의 선택형 [서브셀 PSF 전달](camera-platform-subcell-psf-transfer.md)은 새 렌더에서 서브셀별 광휘를 보존하고 수신 픽셀 적분 PSF의 위치 보간을 통해 RAW까지 연결한다. 기존 v1 셀 평균 아티팩트에는 사후 복원되지 않는다.
