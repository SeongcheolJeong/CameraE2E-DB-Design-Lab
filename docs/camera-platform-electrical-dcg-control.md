# Fixed HCG/LCG observation feedback

Development source `0.16.1.dev6` adds `camera_electrical_control_capture_program_v2` under the existing `electrical_control_v1` runtime. A v2 program requires a linear or nonlinear shared-charge readout model and an immutable `observation_readout_id` of `HCG` or `LCG`. The existing v1 program remains single-readout only. The exposure policy algorithm and schema remain v1.

Each row's exposure integrates the actual scene and optional PWM waveform. One retained PD population is advanced once, including prior residual charge and declared gap dark generation. The same delivered population is read through both fixed conversion paths. Both integer RAW paths are retained; only the selected path's own ADC black-relative code statistics enter the controller. A command can change a later exposure after its declared readiness and latch constraints. Neither path is treated as a separately exposed frame. Acquisition gain is fixed at 1 for paired models; per-path analog/digital gains belong to the immutable readout model. The full reachable exposure interval is checked against scene coverage, timing and both path-model domains before capture.

Four templates provide linear/nonlinear HCG/LCG feedback. The draft exposes a fixed observation selector; saving creates a new immutable program. The Test plan binds the selected path and index. Traces preserve actual applied settings, selected RAW format, observation statistics, command events and an independent preview path. The default capture preview is HCG, including when LCG controls exposure, and the UI labels this distinction.

Response studies compare fixed exposure and AE using the selected observation path, while preserving the complete two-path RAW artifact and separately labelled HCG preview. Code-domain ISP may select either acquired path independently of the AE meter. Its source verifier replays the original controller from the authored meter's original integer RAW, checks actual timing and commands, then passes only the selected display RAW and actual acquisition settings to ISP. Shared-charge acquisition IDs and path-specific gains remain attached. The existing bounded ISP candidate comparison accepts this source contract.

This is a declared behavioral simulation with code-domain processing, not a stateful HDR reconstruction or a physical LFM accuracy claim. No dynamic path switching, exposure normalization, photocharge inversion, trap/CDS circuit solution, motion compensation or automatic optimal model promotion is added. Initial PD state, transfer efficiency and readout model assumptions remain explicit. Physical measurements remain absent, physical validation unestablished and total predictive uncertainty unknown. Primary v0.15 and the independent v0.16 installation candidate remain separate from this source-only development extension.
